--- PAIR 1: average   (recommended - best tables) ---

CORRECT (left box):

def average(nums):
    if len(nums) == 0:
        return 0
    return sum(nums) / len(nums)

DEFECT (right box): change the last line to

    return sum(nums) / (len(nums) - 1)

  catches it:      assert average([2, 4]) == 3        -> CAUGHT   3.0 vs 6.0
  passes on both:  assert average([0, 0]) == 0        -> NOT CAUGHT
  broken test:     assert average([2, 4]) == 99       -> INVALID
  Find inputs that differ: 4 clear rows each side.
  Story: "dividing by n-1 instead of n - the classic off-by-one."


--- PAIR 2: apply_discount   (most intuitive for non-CS professors) ---

CORRECT (left box):

def apply_discount(price, percent):
    return price - (price * percent / 100)

DEFECT (right box): delete the "/ 100"

    return price - (price * percent)

  catches it:      assert apply_discount(100, 10) == 90   -> CAUGHT   90.0 vs -900
  passes on both:  assert apply_discount(0, 10) == 0      -> NOT CAUGHT
  Story: "a 10% discount became 1000%. But test it with a price of zero
          and both versions look fine."


--- PAIR 3: count_vowels   (best story, thinner search table) ---

CORRECT (left box):

def count_vowels(s):
    return sum(1 for c in s.lower() if c in "aeiou")

DEFECT (right box): delete the "u" from the vowel string

    return sum(1 for c in s.lower() if c in "aeio")

  catches it:      assert count_vowels("blue") == 2    -> CAUGHT   2 vs 1
  passes on both:  assert count_vowels("hello") == 2   -> NOT CAUGHT
  Story: "any test word without a 'u' in it misses this completely."
  NOTE: "Find inputs that differ" returns only one differing row here.
        Use the two tests above rather than the search for this pair.


AVOID bugs that only one exact input can expose, for example
changing 13 <= age to 13 < age. The search finds nothing to show,
because that single value is not in the input pool.
